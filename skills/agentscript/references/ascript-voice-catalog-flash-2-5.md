# ElevenLabs Flash v2.5 Voices

This page lists the ElevenLabs Flash v2.5 voice personas and the locales each one supports. Use Flash v2.5 for non-English languages; for English, use [ElevenLabs Flash v2 Voices](ascript-voice-catalog-flash-2.md) instead. To use one, select the ElevenLabs Flash v2.5 model and set a `persona_id` in the `modality voice` block. If you select ElevenLabs Flash v2.5 without a `persona_id`, the agent falls back to the voice marked **(default)**. For how to select a model and configure a voice, see [Configure Voice Models in Agent Script](ascript-voice.md).
