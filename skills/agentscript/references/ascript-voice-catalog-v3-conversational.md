# ElevenLabs v3 Conversational Voices

This page lists the ElevenLabs v3 Conversational voice personas and the locales each one supports. ElevenLabs v3 Conversational is the default voice model, so you don't have to set a `persona_id` to use it — each locale falls back to the voice marked **(default)**. Set a `persona_id` only when you want a specific voice. For how to select a model and configure a voice, see [Configure Voice Models in Agent Script](ascript-voice.md).

ElevenLabs v3 Conversational voices don't use the `speed` or `similarity` parameters, and `stability` defaults to 0.5.
