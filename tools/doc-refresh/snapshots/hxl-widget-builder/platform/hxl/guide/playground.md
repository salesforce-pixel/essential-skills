# Explore Widgets in HXL Playground

HXL Playground (<https://www.headlessexperiencelayer.com>) is an interactive, browser-based tool for learning and building with the Headless Experience Layer (HXL). Describe your UI as declarative JSON, and the playground renders the UI natively across multiple surfaces.

- **[Components](/docs/platform/hxl/guide/playground-components.md)**: Learn about HXL components and their properties.
- **[Widgets](/docs/platform/hxl/guide/playground-widgets.md)**: Compose components into complete, reusable UI.
- **[Tutorials](https://www.headlessexperiencelayer.com/#01-hello-world)**: Learn HXL concepts step by step, from a single text block to a full widget.

Use the playground's top navigation bar to switch pages. To change the theme, select light, dark, or system mode at the top of any page.

![Navigation bar in HXL playground](https://a.sfdcstatic.com/developer-website/sfdocs/headless-experience-layer/media/playground-nav.png)

## Next Steps

- Browse the [components reference](/docs/platform/hxl/references/hxl-reference-about/) for the properties and behavior of each component.
- Work through the [Tutorials](https://www.headlessexperiencelayer.com/#01-hello-world) to learn HXL concepts.
- Compose your own widget on the [Widgets](https://www.headlessexperiencelayer.com/#widget/local) page and preview it across surfaces.
