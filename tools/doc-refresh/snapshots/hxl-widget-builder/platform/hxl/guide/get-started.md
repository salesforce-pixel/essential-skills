# Get Started with Headless Experience Layer

Headless Experience Layer (HXL) is a unified experience engine and platform designed to deliver consistent, portable, and rich user experiences across various surfaces. HXL is a UI technology-agnostic platform that enables developers to “write once and run anywhere.”

![How HXL works](https://a.sfdcstatic.com/developer-website/sfdocs/headless-experience-layer/media/HXLhowItWorks3.png)

Use HXL to build widgets for interactive and rich content, such as a dashboard that summarizes your data or a table with action buttons. Build a widget once and deploy it to Agentforce, ChatGPT, Claude, and Slackbot. By using HXL widgets, agent responses and conversational UI can render natively on any target surface without requiring developers to rebuild features for each channel.

## Key HXL Advantages

- **Operational agility:** Build logic once; deploy to any surface using the same HXL widgets. Widgets provide interactive and reusable UI blocks that decouple your business logic from presentation.

- **Deterministic governance:** Ground all AI interactions in the same metadata and follow the same deterministic business rules via centrally managed AI guardrails no matter where they occur.

- **Reduced integration tax:** Define every interaction with Custom Lightning Types, eliminating the need for custom API bridges between your Salesforce org and external UI surfaces.

- **Inherited security:** Every experience automatically inherits Salesforce’s native permissions and sharing models ensuring secure interactions.

## Build Rich UI with HXL Widgets

To get started, review the [prerequisites](/docs/platform/hxl/guide/prerequisites.md). Set up your development environment and enable HXL in your org.

Then, learn about HXL components and build widgets in the [HXL Playground](https://www.headlessexperiencelayer.com/playground/). Experiment with mock data, refine your custom code, and copy the resulting widget definitions to use in your agentic HXL app.

Alternatively, speed up development by vibe coding widgets with [Agentforce Vibes](https://developer.salesforce.com/docs/platform/agentforcevibes/guide/afv-get-started.md).
