## Integrate Agentforce Conversation Client Web SDK with External Apps

To integrate this conversational experience into custom external web applications, developers use the Agentforce Conversation Client Web SDK. The SDK abstracts away the complexities of real-time Employee Agent connectivity, enabling complex rich UI and granting developers granular control over the ACC UI.

### When to Use the Agentforce Conversation Client Web SDK

Review these guidelines to determine if this is the correct integration path for your project:

- **External Applications**: Use the ACC Web SDK if you are integrating a conversational Employee Agent into an external website or custom frontend hosted outside of Salesforce. This SDK provides standard ACC UI features out of the box, such as streaming text, feedback, brand styling and theming.
- **Headless Integrations**: Don’t use the ACC Web SDK if you are building a purely headless Employee Agent integration, such as an Employee Agent that runs via SMS, WhatsApp, or a custom native mobile implementation.
