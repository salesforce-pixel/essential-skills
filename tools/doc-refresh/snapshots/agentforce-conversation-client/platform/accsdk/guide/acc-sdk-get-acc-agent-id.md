## Get Your Employee Agent ID

To deploy a specific Employee Agent via the Web SDK, configure the correct integration user permissions and retrieve the unique identifier for your Agent.

1. From **Setup**, in the **Quick Find** box, enter `Agentforce Agents`, and then select **Agentforce Employee Agent**.
2. Locate the Employee Agent that you want to embed in your external application.
3. Open the Agent record and copy its 18-character Salesforce record ID from the URL. You must provide this `agentId` during the ACC SDK initialization.
