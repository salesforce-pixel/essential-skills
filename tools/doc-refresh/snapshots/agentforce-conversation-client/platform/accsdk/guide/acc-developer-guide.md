# Agentforce Conversation Client

Explore the Agentforce Conversation Client (ACC) to integrate Agentforce Employee Agent (AEA) conversation experiences into both Salesforce Lightning and external web applications.

### Key Purpose:

- Understand how ACC works, provides the infrastructure for continuous real-time streaming of Agentforce Employee Agent (AEA) messages, and renders rich components using Lightning Types integration.
- Programmatically control the ACC panel to open, close, switch between Employee Agents, and execute utterances.
- Integrate Agentforce conversational experiences into your external web apps.
  :::note
  If you are integrating the ACC UI into a custom external web application hosted outside of Salesforce, see [Agentforce Conversation Client Web SDK](/docs/platform/accsdk/guide/acc-sdk-overview.md).
  :::

### Explore the Guides:

- **[Introducing Agentforce Conversation Client](/docs/platform/accsdk/guide/acc-get-started.md):** Understand how the ACC works, its core capabilities (like streaming and dynamic rendering), and how it delivers value across different user interfaces.
- **[Agentforce Conversation Client API](/docs/platform/accsdk/guide/acc-api.md):** Learn how to programmatically open, close, and execute utterances in the native Agentforce side panel using custom Lightning Web Components (LWCs) inside Salesforce.
- **[Agentforce Conversation Client Web SDK](/docs/platform/accsdk/guide/acc-sdk-overview.md):** Learn how to authenticate and embed the conversational Employee Agent into custom, external web applications hosted outside of Salesforce.
- **[Integrate Agentforce Conversation Client in React Applications](https://developer.salesforce.com/docs/platform/einstein-for-devs/guide/reactdev-acc.md):** Learn how to build internal React applications with conversational capabilities using Agentforce Vibes and Lightning Out 2.0.
