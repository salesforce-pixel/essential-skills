# AiAgentSessionTag DLO Mappings

The AiAgentSessionTag object is a Salesforce standard object that you can ingest and map to Data Model Objects (DMOs) for use in Data Cloud-powered features and agents.

![Object Mapping Diagram for AiAgentSessionTag](https://a.sfdcstatic.com/developer-website/sfdocs/data-cloud/media/data-cloud-dmo-mapping/standard_mappings/AiAgentSessionTag_obj_mappings_v2.svg)

## Mappings to the AiAgentTagAssociation DMO Object

The AiAgentSessionTag DLO is mapped to the [AiAgentTagAssociation DMO](/docs/data/data-cloud-dmo-mapping/guide/c360dm-si-aiagenttagassociationdmo-dmo.md).

![Mapping diagram for AiAgentSessionTag DLO to AiAgentTagAssociation DMO](https://a.sfdcstatic.com/developer-website/sfdocs/data-cloud/media/data-cloud-dmo-mapping/standard_mappings/AiAgentSessionTag_to_AiAgentTagAssociationDmo_def_v2.svg)

- The AiAgentSessionTag DLO field **Id** maps to the AiAgentTagAssociation DMO Object **Id** field.
- The AiAgentSessionTag DLO field **AiTagDefAssocId** maps to the AiAgentTagAssociation DMO Object **AiAgentTagDefinitionAssociationId** field.
- The AiAgentSessionTag DLO field **AiTagValueId** maps to the AiAgentTagAssociation DMO Object **AiAgentTagId** field.
- The AiAgentSessionTag DLO field **SessionIdentifier** maps to the AiAgentTagAssociation DMO Object **AiAgentSessionId** field.
- The AiAgentSessionTag DLO field **InteractionIdentifier** maps to the AiAgentTagAssociation DMO Object **AiAgentInteractionId** field.
- The AiAgentSessionTag DLO field **IntentIdentifier** maps to the AiAgentTagAssociation DMO Object **AiAgentMomentId** field.
- The AiAgentSessionTag DLO field **AssociationReason** maps to the AiAgentTagAssociation DMO Object **AssociationReasonText** field.
- The AiAgentSessionTag DLO field **ValueText** maps to the AiAgentTagAssociation DMO Object **ValueText** field.
- The AiAgentSessionTag DLO field **SourceType** maps to the AiAgentTagAssociation DMO Object **SourceType** field.
- The AiAgentSessionTag DLO field **AttributeText** maps to the AiAgentTagAssociation DMO Object **AttributeText** field.
- The AiAgentSessionTag DLO field **OutcomeType** maps to the AiAgentTagAssociation DMO Object **OutcomeType** field.
- The AiAgentSessionTag DLO field **SessionStartTimestamp** maps to the AiAgentTagAssociation DMO Object **AiAgentSessionStartTimestamp** field.
- The AiAgentSessionTag DLO field **CreatedDate** maps to the AiAgentTagAssociation DMO Object **CreatedDate** field.
- The AiAgentSessionTag DLO field **CreatedById** maps to the AiAgentTagAssociation DMO Object **CreatedByUserId** field.
- The AiAgentSessionTag DLO field **DataSource** maps to the AiAgentTagAssociation DMO Object **DataSourceId** field.
- The AiAgentSessionTag DLO field **DataSourceObject** maps to the AiAgentTagAssociation DMO Object **DataSourceObjectId** field.
- The AiAgentSessionTag DLO field **SfdcOrganizationId** maps to the AiAgentTagAssociation DMO Object **ExternalSourceId** field.
