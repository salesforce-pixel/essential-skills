# Access Salesforce APIs

With Data SDK, you can access any [Connect REST API](https://developer.salesforce.com/docs/platform/connect-rest-api/references/connect-rest-api-about/about.md) resource from your multi-framework app. Many Salesforce features provide their own Connect API resources, such as [Data 360 Connect REST API](https://developer.salesforce.com/docs/data/connectapi/references/spec), [CRM Analytics REST API](https://developer.salesforce.com/docs/atlas.en-us.bi_dev_guide_rest.meta/bi_dev_guide_rest/bi_rest_overview.htm), and [Salesforce Industries REST API](https://developer.salesforce.com/docs/atlas.en-us.api_rest_industries.meta/api_rest_industries/intro.htm). We recommend that you check the reference documentation for the feature you're accessing.

Here are common endpoints you can use with Data SDK and the apps they support. See the differences between [internal and external apps](/docs/platform/multiframework/guide/mfw-generate-app.md).

In the endpoint, `v{version}` represents the API version you work with, such as `v66.0`.

| Endpoint                                                                              | Purpose                                                                                                                                                                                                                                                                                           | Internal (B2E) Apps | External (B2B and B2C) Apps |
| :------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------ | :-------------------------- |
| `/services/apexrest/*`                                                                | [Custom Apex REST resources](https://developer.salesforce.com/docs/atlas.en-us.apexcode.meta/apexcode/apex_rest_intro.htm) for accessing your Apex classes and methods                                                                                                                            | ✓                   | ✓                           |
| `/services/data/v{version}/graphql`                                                   | [GraphQL API endpoint](https://developer.salesforce.com/docs/platform/graphql/guide/graphql-about.md) for querying and mutating record data with a single request                                                                                                                                 | ✓                   | ✓                           |
| `/services/data/v{version}/ui-api/records`                                            | [UI API records resources](https://developer.salesforce.com/docs/atlas.en-us.uiapi.meta/uiapi/ui_api_get_started.htm) for reading and writing record data                                                                                                                                         | ✓                   | ✓                           |
| `/services/data/v{version}/ui-api/search-info`                                        | [UI API search resources](https://developer.salesforce.com/docs/atlas.en-us.uiapi.meta/uiapi/ui_api_get_started.htm) for retrieving search suggestions and scope information                                                                                                                      | ✓                   | ✓                           |
| `/services/data/v{version}/ui-api/layout`                                             | [UI API layout resources](https://developer.salesforce.com/docs/atlas.en-us.uiapi.meta/uiapi/ui_api_get_started.htm) for retrieving metadata-driven page and record layouts                                                                                                                       | ✓                   | ✓                           |
| `/services/data/v{version}/ui-api/session/csrf`                                       | [UI API CSRF token resource](https://developer.salesforce.com/docs/atlas.en-us.uiapi.meta/uiapi/ui_api_get_started.htm) for protecting requests against cross-site request forgery                                                                                                                | ✓                   | ✓                           |
| `/services/data/v{version}/ui-api/*`                                                  | [UI API resources](https://developer.salesforce.com/docs/atlas.en-us.uiapi.meta/uiapi/ui_api_get_started.htm) for reading and writing record data, metadata-driven layouts, and related UI data                                                                                                   | ✓                   | ✓                           |
| `/services/data/v{version}/chatter/*`                                                 | [Chatter Connect API resources](https://developer.salesforce.com/docs/platform/connect-rest-api/references/connect-rest-api-chatter) for accessing Chatter feeds, groups, and users                                                                                                               | ✓                   | ✓                           |
| `/services/data/v{version}/chatter/users/me`                                          | [Current Chatter user resource](https://developer.salesforce.com/docs/platform/connect-rest-api/references/connect-rest-api-chatter) for retrieving the profile of the running user                                                                                                               | ✓                   | ✓                           |
| `/services/data/v{version}/chatter/users/{userId}`                                    | [Chatter user by ID resource](https://developer.salesforce.com/docs/platform/connect-rest-api/references/connect-rest-api-chatter) for retrieving the profile of a specific user                                                                                                                  | ✓                   | ✓                           |
| `/sfsites/c/_nc_external/system/security/session/SessionTimeServlet`                  | [User session timeouts resource](https://help.salesforce.com/s/articleView?id=xcloud.security_overview_sessions.htm) for checking the remaining time before the session expires                                                                                                                   | ✓                   | ✓                           |
| `/secur/logout.jsp`                                                                   | Logout for ending the current user session                                                                                                                                                                                                                                                        | ✓                   | ✓                           |
| `/services/data/v{version}/connect/file/upload/config`                                | [File upload config resource](https://developer.salesforce.com/docs/platform/connect-rest-api/references/connect-rest-api-files#tag/Files-Resources) for retrieving the settings needed to upload files                                                                                           | ✓                   | ✓                           |
| `/services/data/v{version}/connect/proxy/ui-telemetry`                                | UI telemetry proxy for sending client-side performance and usage metrics                                                                                                                                                                                                                          | ✓                   | ✓                           |
| `/services/data/v{version}/connect/*`                                                 | [Connect REST API resources](https://developer.salesforce.com/docs/platform/connect-rest-api/references/connect-rest-api-core) for accessing Salesforce feature data such as files, feeds, and communities                                                                                        | ✓                   |                             |
| `/services/data/v{version}/connect/cms/delivery/channels/{channelId}/contents`        | [CMS channel content delivery resource](https://developer.salesforce.com/docs/platform/connect-rest-api/references/connect-rest-api-cms) for retrieving published managed content from a channel                                                                                                  |                     | ✓                           |
| `/services/data/v{version}/connect/cms/channels/{channelId}/searchable-content-types` | [CMS searchable content types resource](https://developer.salesforce.com/docs/platform/connect-rest-api/references/connect-rest-api-cms#tag/CMS-Managed-Content-Resources/operation/getManagedContentTypeSearchableCollection) for retrieving the content types available for search in a channel |                     | ✓                           |

We recommend that you use optional chaining `fetch?.()` instead of a non-null assertion `fetch!.()`. Optional chaining is useful when you want to use fetch in a shared or cross-surface utility. If you're not sure where your code is run, use optional chaining and handle the response appropriately.

:::tip
The read-data examples in the [Multi-framework recipes repo](https://github.com/trailheadapps/multiframework-recipes) demonstrate how to call Chatter Connect API, Apex REST, and UI API REST.
:::
